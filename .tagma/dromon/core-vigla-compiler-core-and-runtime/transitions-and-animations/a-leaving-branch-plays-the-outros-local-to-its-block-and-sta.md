A transition belongs to the block whose branch renders its element. When a branch leaves, the blocks ask `pause` to play the outros of that branch's own elements and of those rendered through components, dynamic `{@render}` or component blocks and `<svelte:element>`'s tag block, which are transparent. A nested `{#if}`, `{#each}`, `{#key}` or `{#await}` makes everything under it non-local, so only its `|global` transitions play. Symmetrically, a local intro plays only when its nearest non-transparent block builds the branch on an update, never on that block's first run, and every intro waits for the mount's `intro` option, `true` unless set. Upstream 5.57.3 reads the same rules from its effect flags (`EFFECT_TRANSPARENT`, `REACTION_RAN`); Vigla takes them from the block that is building: `building` around each branch or row a block creates, `seeThrough` for the transparent swaps, and component instance owners (root effects linked under a branch) counted as transparent.

A paused branch or row stays in the DOM and its key stays known, hidden from every batch so nothing in it updates while it leaves, until all its outros finish; then it is destroyed, or stashed if a held batch still selects it. Selected again before that, it resumes in place without rebuilding: a bidirectional transition reverses from where it is, while an out-only transition resets and starts afresh if the branch leaves again. An each row entering or moving is placed right after the row before it in the new order, ahead of rows still leaving there, as upstream places it; the list keeps a start node of its own — the server's open marker when hydrated, else an empty text node — so the first row has a position to follow. With `animate:`, each list measures its retained rows and rows starting an outro in its commit change's preparation, before any block of the wave pins, stashes or reorders a row. Retained rows animate a task later; an outgoing element with no browser-reported animations is taken out of flow and offset with an inline transform, released when its outro ends, before the row is stashed or removed, and before a reselected row resumes. A reselected row gets no FLIP, as upstream leaves it. An element with an animation keeps its existing positioning because animated styles may override that offset.

Geometry is read in one layout pass a task after the transitions that need it register: every participant already known when its options factory returns is captured first, matched crossfade senders are taken out of flow, and only then are both endpoints measured, so no participant's measurement sees another's displacement. A source pose is what the element displayed before the commit wave touched the DOM: Branches and List preparation captures every transition element of leaving and reselected branches and rows before any block of the wave applies, so one block's insertion cannot displace another block's sender. A crossfade factory resolved later than that pass uses ordinary live measurement or its fallback. Under its own transform, or under a transformed, perspective or zoomed ancestor, an element's viewport delta is no local translation. A capture then probes the element's frame: its own transform is overridden inline with `!important` and collapsed to a point at four box corners, which gives the exact homography from its box to the viewport, and its style attribute text is then restored. Crossfade, FLIP and the out-of-flow offset map the other pose's corners through that frame's inverse and animate in the element's own transform units. A pose with no transform on itself or its ancestors maps by translation alone. Two such poses keep the viewport arithmetic, which then is exact. A frame whose source and target differ only by translation and scale is exact. A rotation across different frames is approximated by the axis-aligned bounds. An element that cannot be probed keeps its pose unmapped, and any pair involving it falls back to the viewport arithmetic. That covers a `transform` or `all` transition that the probe would start, SVG, an unrendered element, and an inline box without a used size. The probe's temporary writes remain visible to MutationObservers. The ancestor walk is cached only within one preparation or one measurement sweep, so a transform applied between the source and target captures is seen. Out-of-flow placement is leased per element and restores only the inline declarations it wrote and nobody changed since. The module tracks the animations it starts on each element: a lease writing a transform offset and a FLIP that moves its element take the transform channels from the module's older animations on that element, which keep running for their other properties, ticks and events. A lease also takes `translate`, `rotate` and `scale` from those animations, since the crossfade replacing them never animates those properties. It writes their captured values inline until it is released, so the pose holds. A browser lets the newest animation override inline styles and older animations, so without this an earlier intro would mask a sender's pin offset, freeze into a FLIP's measured base, and reappear when the newer motion ends. Authored animations are never touched.

While a branch leaves, its declared deriveds evaluate in its last-selected view, including synchronous transitive reads of outside-owned deriveds, so deleting guarded input cannot reach an outgoing computation. Direct reads and outside-owned derived reads outside that computation keep the current batch's values. The view starts before outro options run and ends after the final tick and `outroend`, before completion destroys or stashes the branch; reselection releases it before reversal callbacks, and direct destruction before cleanup. A held batch may evaluate its explicitly selected reactions in its own view without changing what the still-running outro callbacks read. Completion releases only its own leave run, so synchronous reselection cannot let an old completion discard a new one.

Managers and movers are kept in `WeakMap`s keyed by the effect that rendered the element, so a destroyed tree leaves none behind.
