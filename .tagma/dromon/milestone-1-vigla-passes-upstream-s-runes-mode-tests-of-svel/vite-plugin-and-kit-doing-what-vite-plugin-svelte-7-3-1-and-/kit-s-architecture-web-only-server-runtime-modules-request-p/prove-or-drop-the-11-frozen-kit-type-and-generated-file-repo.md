- [#14295 `resolve` return value doesn’t match type / `ResolvedPathname` type is misleading](https://github.com/sveltejs/kit/issues/14295) · **Proved:** `own/kit/resolved-paths` observes the public HTTP endpoint returning `./about` from `resolve('/about')`, then checks that value against the generated public return type. Upstream 3.1.0 rejects it; Vigla accepts server-relative forms. Commit 7c11542d82cabba818bd698ecd3c61308ee92dde; Sol review found no issues.
- [#14609 Route files’ type imports don’t work when imported via JSDoc `@import`](https://github.com/sveltejs/kit/issues/14609) · **Dropped, external checker producer:** svelte-check 4.7.6 and 4.7.7 with TypeScript 6.0.3 report the async Promise diagnostic for a JSDoc `@import` `PageLoad` on Kit 3.1.0/Svelte 5.57.3/plugin 7.3.1; inline JSDoc import passes, as do both forms under tsrs 0.18.0. A standalone JavaScript `rootDirs` fixture without Kit imports reproduces the same distinction on both checker versions. Evidence and limits in [[2e546434]]; no Kit fix was made.
- [#15536 `RouteId` is not a valid param for `resolve()`](https://github.com/sveltejs/kit/issues/15536) · **Proved:** `own/kit/route-union` generates 32 static route ids and passes a `RouteId` variable to public `resolve`. Upstream 3.1.0 fails TS2345; Vigla keeps parameter-free ids in one argument tuple while parameterized branches remain correlated. The literal and invalid-route controls pass. Commit 7c11542d82cabba818bd698ecd3c61308ee92dde; Sol review found no issues.
- [#16437 `ResolvedPathname` allows `'//'`](https://github.com/sveltejs/kit/issues/16437) · **Proved:** `own/kit/resolved-paths` uses root `trailingSlash: 'always'` with base `/base`; upstream 3.1.0 rejects `/base/` and accepts `//`, `/base//` and `/else/about`. Vigla normalizes the empty root and uses the configured absolute prefix; its positive and negative type controls pass. Commit 7c11542d82cabba818bd698ecd3c61308ee92dde; Sol review found no issues.
- [#17450 Layout load types remain stale when a child page gains or loses a load export](https://github.com/sveltejs/kit/issues/17450) · **Proved:** `own/kit/layout-load-types` removes and restores the sole child's load through the live Vite watcher. Upstream 3.1.0 refreshes the child but leaves the parent constraint stale (checker exits 0 instead of reporting required `title`); Vigla reports parent TS2322 after removal and passes again after restoration. Existing Vigla behavior, no producer edit needed. Commit 7c11542d82cabba818bd698ecd3c61308ee92dde; Sol review found no issues.
- [#17464 `svelte-kit sync` cache doesn't work](https://github.com/sveltejs/kit/issues/17464) · **Proved:** `own/kit/sync-generated` runs the public CLI twice and asserts stable root/nested declaration mtimes; Kit 3.1.0/Svelte 5.57.3/plugin 7.3.1 fails upstream, Vigla passes one entry.
